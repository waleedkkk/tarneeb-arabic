# سجل التشخيص المحلي

## الغرض

يحفظ التطبيق آخر 30 خطأً تشخيصيًا على الجهاز نفسه لمساعدة فريق التطوير على ربط خطأ ظاهر في APK بالإصدار والمنصة ومسار الخطأ. لا يرسل التطبيق هذا السجل تلقائيًا عبر الشبكة.

## ما يُسجل وما لا يُسجل

| يُسجل | لا يُسجل |
| --- | --- |
| وقت الخطأ ونوعه | أوراق أي لاعب أو أسماء البطاقات |
| رسالة الخطأ والـ stack بعد التنقيح | رمز الغرفة ومفتاحها وToken الاتصال |
| إصدار التطبيق ورقم البناء والمنصة | عنوان المضيف أو المنفذ أو عنوان الشبكة |
| أخطاء React وJavaScript وأخطاء الغرفة المعالجة | محتوى حالة المباراة أو توزيع الأيدي |

يُطبق التنقيح قبل الكتابة إلى التخزين وقبل المشاركة. كما يحدد النظام طول كل نص تشخيصي إلى 1200 حرف.

## طريقة الاستخدام على الهاتف

بعد حدوث خطأ، أعد فتح اللعبة ثم انتقل إلى **الإعدادات → التشخيص**. يعرض القسم عدد السجلات وآخر رسالة، ويوفر الأزرار التالية:

| الزر | النتيجة |
| --- | --- |
| تحديث | يعيد قراءة السجل المحفوظ على الجهاز |
| نسخ السجل | ينسخ تقرير JSON آمن إلى الحافظة لإلصاقه في المحادثة |
| مشاركة | يفتح قائمة المشاركة الأصلية لإرسال نص التقرير |
| مسح السجل | يحذف السجل من الجهاز نهائيًا |

يتطلب زر النسخ حزمة `expo-clipboard`، ولذلك يجب إنشاء APK جديد بعد هذا التغيير حتى تظهر الميزة في التطبيق المثبت.
